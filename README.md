# Dhanashri Phadtare — Developer Portfolio

A responsive portfolio website for job applications, focused on Python, backend development and AI applications.

## Files
- `index.html` — portfolio page
- `style.css` — responsive styling
- `README.md` — publishing instructions

## Publish with GitHub Pages
1. Create a public repository named `portfolio`.
2. Upload `index.html` and `style.css`.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Choose `main` and `/ (root)`, then Save.
6. Use the generated GitHub Pages URL as your portfolio link.
